# Mohamad Moukayed — Engineering Portfolio

A responsive static portfolio built with HTML, CSS, and JavaScript. Open `index.html` directly in a browser, or run a local static server from this directory:

```powershell
python -m http.server 8000
```

## Personalize it

- Add contact details in the `profileLinks` object near the top of `app.js`. Leave a value blank to keep its clearly labeled prompt visible.
- Replace the project media placeholders in `index.html` with your photographs, screenshots, or video embeds. The sumo robot diagrams are labeled illustrations, not photographs.
- Edit project descriptions, statuses, competition details, and skills in `index.html` as your work develops.

The portfolio uses only the details supplied for this site. It does not add dates, contact URLs, claims of completed work, or competition results that were not provided.
